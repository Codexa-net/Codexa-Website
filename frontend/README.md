# Codexa Dashboard

لوحة تحكم إدارية لوكالة Codexa — Next.js 16 (App Router) + TypeScript + Tailwind CSS v4، بتصميم RTL كامل مطابق لملفات الفيجما.

## التشغيل

```bash
npm install
npm run dev
```

يفتح المشروع تلقائيًا على `/dashboard`.

## البنية

- `app/dashboard/*` — كل صفحات اللوحة (نظرة عامة، المشاريع، العملاء، الخدمات، طلبات التواصل، المستخدمون، إعدادات الموقع، الملف الشخصي)
- `components/ui/*` — عناصر عامة (Button, Card, Badge, FormField, Toggle, DeleteDialog...)
- `components/layout/*` — Sidebar و Topbar
- `components/charts/*` — شارت تقدم المشاريع (Area) وشارت حالة المشاريع (Donut) باستخدام Recharts
- `lib/data.ts` — بيانات تجريبية (mock) لكل الكيانات: مشاريع، عملاء، خدمات، طلبات تواصل، مستخدمين. استبدلها لاحقًا بطلبات API حقيقية.

## ملاحظات

- كل شاشات الإضافة/التعديل تستخدم نفس الفورم (Component واحد لإضافة وتعديل كل كيان) وترجع لصفحة القائمة عند الحفظ (حاليًا بدون اتصال فعلي بسيرفر — جاهزة لربطها بـ API).
- نافذة تأكيد الحذف (`DeleteDialog`) مشتركة بين كل الشاشات (مشاريع/عملاء/خدمات/مستخدمين).
- خط Cairo يتم تحميله من Google Fonts عبر `<link>` في `app/layout.tsx`؛ يحتاج اتصال إنترنت عند فتح الموقع في المتصفح.
- شاشة طلبات التواصل تفتح تفاصيل الطلب في Drawer جانبي بدل صفحة منفصلة.
